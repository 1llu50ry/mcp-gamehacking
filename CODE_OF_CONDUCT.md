# Code of Conduct

Our standards are short:

1. Be kind and respectful. Attack ideas, not people.
2. Zero tolerance for harassment, doxxing, hate speech, or discrimination (race, gender, orientation, religion, nationality, ability, body size, age, experience).
3. Zero tolerance for using this project to grief, defraud, dox, or harm other players — see the Ethics section of the README.
4. English works best, but we accept PRs and issues in any language. If you need a reviewer who speaks yours, flag it.
5. Research contributions must respect the project owner's RE / platform. Don't paste copyrighted binaries or decompiled production source code into issues.

## Enforcement

Report violations to the maintainer by email (listed on the GitHub profile) or by opening a private security advisory. All reports are confidential.

Consequences escalate: private warning → public warning → temporary ban → permanent ban. Serious violations (threats, doxxing, bypassing an active anti-cheat for a game you don't own) skip straight to permanent ban.

Based on the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
